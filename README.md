# RIEN 서버 가이드

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면과 기능. 디자인을 바꿀 때만. |
| `data.json` | 모든 수치와 문구. **내용 수정은 여기서만** |

### 자주 쓰는 수정 위치

- **강화 재료·확률** → `enhance`
  - `costStone`, `costMeso` 를 바꾸면 계산기도 같이 바뀝니다.
  - 증폭 확률표는 `enhance.amp.table` 의 `["결과","확률","수치 변동"]` 형식입니다.
- **영혼석 재료** → `soul` 의 `fragPerUnit` / `purifyPerUnit` / `mesoPerUnit`
- **히든 스킬** → `hiddenSkills` 에 `{ "name", "icon", "category", "meso", "desc" }` 추가 (`icon` 은 아이템과 같은 base64 형식, 없어도 됩니다)
- **연금술 아이템** → `alchemy.items` 에 `["분류","이름", 경험치, "하위 재료"]` 추가
  - 새 분류를 넣으면 탭이 자동으로 생깁니다.
  - 레시피는 `alchemy.recipes` 에 아이템 이름을 키로 넣습니다. 형식은 `"사악한 불꽃": {"icon":"data:image/png;base64,…", "rate":"30.5% (30% + 0.5%)", "mats":["재료 10개"], "meso":"2,736,000", "qty":1, "limit":"1일 5개"}` 이고 `qty` 와 `limit` 은 없으면 생략합니다.
  - 레시피를 넣은 아이템은 표에 아이콘과 성공 확률이 붙고, 행을 누르면 재료 목록이 아래에 펼쳐집니다. 이름은 `alchemy.items` 의 이름과 정확히 같아야 연결됩니다.
  - 재료 아이콘은 `alchemy.matIcons` 에 `"재료 이름": "data:image/png;base64,…"` 로 넣습니다. 키는 개수를 뺀 이름(`"뇌전 수리검 1개"` → `"뇌전 수리검"`)이고, 등록된 재료는 모든 레시피에서 자동으로 아이콘이 붙습니다. 없으면 점선 네모로 표시됩니다.
  - 재료 조합이 두 가지인 아이템은 `"alt":{"mats":["골드 일비 표창 1개"],"meso":"7,583,000"}` 을 추가하면 "또는 이 재료로도 제작" 항목이 붙습니다.
  - 하위 재료 열을 쓰는 분류는 `alchemy.upgradeCategories` 에 이름을 넣어주세요.
- **아이템 정보** → `items.list` 에 아이템 추가
  - `rows` 는 위쪽 요약 항목, `stats` 는 확률표입니다.
  - `stats` 의 각 줄은 `{"name":"힘","tiers":[["+0","90%"],["+1~+3","5%"], …]}` 형식이고, 칸 수는 `items.tierHeaders` 와 맞춰주세요.
  - 드랍 아이템은 `"drops":[["몬스터명","0.003%"], …]` 를 넣으면 드랍표가 붙습니다. `stats` 와 `drops` 는 둘 중 하나만 써도 되고, 둘 다 없으면 `rows` 요약만 나옵니다.
  - `drops` 에 적은 몬스터는 **몹별 드랍 탭과 전역 검색에 자동으로 등록**됩니다. 따로 입력할 필요 없습니다.
  - 아이콘은 `"icon":"data:image/png;base64,..."` 형식으로 넣습니다. 인게임 스크린샷에서 아이콘만 잘라 32×32 PNG로 만든 뒤 base64 로 변환해서 붙여넣으면 됩니다. 아이콘이 없으면 이름만 나옵니다.
  - 아이템을 추가하면 상단 버튼이 자동으로 늘어납니다.
- **스킬** → `skills`
  - 궁극기는 `skills.ultimates` 에 `{"group":"전사","job":"히어로","name":"스킬명","type":"궁극기","rows":[["항목","값"], …]}` 형식으로 추가합니다.
  - 패치 내역은 `skills.patches` 에 `{"group":"전사","job":"히어로","changes":["스킬명 — 변경 내용", …]}` 형식입니다.
  - `group` 은 상단 필터 버튼이 되고, 새 값을 쓰면 버튼이 자동으로 생깁니다.
- **보스** → `bosses.list` 에 `{"name":"자쿰","level":140,"type":"보스, 선공, 비언데드","location":"알 수 없음","stats":[["체력","110,000,000"], …],"drops":[[2,"아이템 1개","100.0%"], …],"dropNote":"확인 중인 항목 메모"}` 형식으로 넣습니다.
  - `drops` 는 `[번호, 아이템, 확률]` 세 칸이고, 보스를 추가하면 상단 탭이 자동으로 늘어납니다.
- **출석체크** → `attendance`
  - 보상은 `list` 에 `{"day":7,"item":"미라클 큐브 30개","icon":"data:image/png;base64,…"}` 형식으로 넣습니다. `icon` 은 없어도 됩니다.
  - 규칙 문구는 `rules` 배열에 한 줄씩 넣으면 표 아래 "출석체크 규칙" 블록에 나옵니다. `note` 는 그 블록 맨 아래 회색 줄입니다.
- **레벨 보상** → `levelRewards`
  - 구간은 `list` 에 `{"level":100,"items":["보상 1개", …]}` 형식으로 넣습니다. 레벨 순서대로 표시됩니다.
  - 보상 아이템 설명은 `itemInfo` 에 `{"name":"명예의 훈장","desc":"…","use":"어빌리티 · 링 옵션 재설정"}` 형식이고 `use` 는 없으면 생략합니다.
  - `pending` 은 아직 확인 못한 내용을 적어두는 칸입니다. 다 채우면 빈 문자열로 비워두세요.
- **투척 무기 공격력** → `alchemy.recipes` 안에 `"atk":36` 을 넣으면 레시피 상세에 공격력 줄이 붙습니다.
- **일일퀘스트 등급** → `quest.dailyGrades`
- **요일별 재료** → `quest.weekday.rows` 에 `["금요일","아이템 1개"]` 추가하고, 다 채우면 `note` 를 지웁니다.
- **필드보스** → `quest.bosses` 에 `["이름", 개수, 경험치, 메소]` 추가
- **퀘스트** → `quest.quests` 에 `{ "name", "mat", "effect", "reward" }` 추가
  - `reward` 는 숫자만 씁니다. 초반루트 순서가 이 값 기준으로 자동 정렬됩니다.
- **홍포 상점** → `shop.items` 에 아이템을 넣고, `shop.order` 에서 묶음을 구성합니다. 아이템에 `icon` 을 넣으면 초반 구매 순서와 전체 목록 표 양쪽에 자동으로 붙습니다.
- **몬스터파크에서 구매하는 장비**(슈피겔만 등, 세트 효과 없이 포인트로 사는 코스튬성 장비) → 홍포 상점이 아니라 `sets.list` 의 `"id":"monsterpark"` 항목 안 `items` 에 넣습니다. 세트 효과가 없는 장비라는 걸 분명히 하려는 목적입니다.
  - `numbered: true` 면 번호가 붙고, `false` 면 점 없는 목록으로 나옵니다.
  - `pre` 에 선행 아이템 이름을 적으면 포인트 계산에 자동 반영됩니다.
- **추천 초반루트** → `route.stages`. 단계 수를 늘리거나 줄이면 퀘스트가 자동으로 나눠집니다.
- **오늘의 팁** → `dailyTips`
- **기본 팁** → `basicTips`
- **세트 효과** → `sets.list` 에 세트 하나당 `{"id","name","groups":[{"label":"공격 직업","tiers":[[3,"올스탯 +1"], …]}],"items":[{"name","icon","rows":[...],"source":{"monster","level","hp","exp","rate"}}]}` 형식으로 넣습니다.
  - `groups` 는 세트 하나 안에 여러 직업군(공격/마력/에반 등)이 있을 때 나눠서 보여줍니다. 하나만 있으면 그룹 하나만 씁니다.
  - `items` 는 그 세트를 구성하는 실제 장비입니다. 아이콘 없이 텍스트만 있어도 되고, `source` 는 특정 보스가 드랍하는 아이템에만 넣으면 획득처가 자동으로 붙습니다.
  - 세트를 추가하면 상단 칩이 자동으로 늘어납니다.
- **강화** → 개요 서브탭은 데이터를 새로 저장하지 않고 `enhance`(일반·최대·추가데미지·증폭)와 `alchemy.recipes['강화 안정제']` 를 그 자리에서 조합해서 보여줍니다. 비용이나 확률을 고치면 개요 화면(비교표·체크리스트·요약카드)도 같이 바뀝니다.
- **직업 가이드** → 데이터를 새로 만들지 않고 `skills.ultimates` 를 그대로 파싱해서 보여줍니다. 궁극기 데이터(데미지, 마릿수/타격수, 공격속도, 공격범위, 공격거리)를 고치면 이 페이지도 자동으로 바뀝니다. 손댈 곳은 없습니다.
- **성장 로드맵** → `roadmap`
  - `phases` 에 `{"no":"03","name":"추가 데미지 성장","from":50,"to":70,"goal":"…","todo":["…"],"links":[["enhance","추가 데미지 보기"]],"next":"다음 단계 이름"}` 형식으로 넣습니다.
  - `why` 는 설명 박스, `warning` 은 빨간 경고 카드(`{"title","desc","goto","cta"}`), `rewardLevels`:[50] 은 해당 레벨 보상을 `levelRewards` 에서 자동으로 끌어와 보여줍니다.
  - `showDmgCost` / `showAmpTable` / `showRainbowOrder` / `showHiddenMove` / `showBossLimit` / `showUnion` 을 `true` 로 두면 강화·상점·히든스킬·퀘스트 데이터를 그 구간에 그대로 불러옵니다. 수치를 복사하지 않으므로 원본만 고치면 로드맵도 같이 바뀝니다.
  - 구간 수는 자유롭게 늘리거나 줄일 수 있고, 상단 타임라인과 레벨 입력 판정이 자동으로 따라갑니다.
- **홈 화면** → `home`
  - `hero` 는 상단 큰 영역(문구와 버튼 두 개), `nowTitle`/`nowDesc` 는 "지금 뭐하지?" 제목입니다.
  - "지금 뭐하지?" 카드와 "처음이라면 이 순서" 단계는 `route.stages` 를 그대로 씁니다. 단계를 고치면 홈과 공략 팁 탭이 함께 바뀝니다. 각 단계의 `goto` 와 `cta` 는 카드 아래 이동 버튼입니다.
  - `groups` 는 목적별 메뉴 묶음(성장·강화·재화·제작·전투), `warnings` 는 "놓치면 안 되는 것" 카드, `findChips` 는 하단 바로가기입니다.
- **메뉴 제목·설명** → `sections`
